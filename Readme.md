# Microsserviço de Usuários

Microsserviço desenvolvido com Java 17 e Spring Boot, responsável pelo gerenciamento de usuários e autenticação do sistema de agendamento de tarefas.

### Funcionalidades
- Cadastro e gerenciamento de usuários
- Autenticação com Spring Security e JWT
- Persistência de dados com PostgreSQL
- Integração com os demais microsserviços

### Tecnologias
Java 17 · Spring Boot · Spring Security · JWT · PostgreSQL · Docker
